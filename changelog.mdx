## 📅 2026 年 5 月

### 🚀 文档站正式上线

- 上线 docs.seeoneapi.com 文档站，提供完整的 API 文档、模型目录、使用场景和开发指南
- 支持全文搜索，方便快速查找

### 🎨 AI 出图平台上线

- [img.seeoneapi.com](https://img.seeoneapi.com) 在线 AI 出图平台上线
- 支持 gpt-image-2，可选 1K / 2K / 4K 分辨率
- 无需写代码，输入提示词即可生成图像

### 🖼️ gpt-image-2 全面支持

- 支持 `/v1/images/generations` 标准接口
- 支持 `/v1/responses` Responses API 格式
- 最高支持 4096×4096（4K）超清输出
- 支持 quality 参数控制图像质量
