## 基本调用

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的API密钥",
    base_url="https://api.seeoneapi.com/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "用 Python 实现一个快排算法"}
    ]
)

print(response.choices[0].message.content)
```

```javascript Node.js
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-你的API密钥',
  baseURL: 'https://api.seeoneapi.com/v1',
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [
    { role: 'user', content: '用 Python 实现一个快排算法' }
  ],
});

console.log(response.choices[0].message.content);
```

```bash cURL
curl https://api.seeoneapi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的API密钥" \

    "model": "gpt-4o",

    ]
```

## 多模态调用（图片输入）

GPT-4o 支持图片输入，你可以发送图片 URL 或 base64 编码：

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "这张图片里是什么？"},
                {
                    "type": "image_url",
                    "image_url": {"url": "https://example.com/image.jpg"}
                }
            ]
        }
    ]
)
```

<Tip>
  也可以使用 base64 编码传图：将 `url` 字段改为 `data:image/jpeg;base64,{base64数据}` 格式。
</Tip>

## 推理模型注意事项

使用 o3 / o4-mini 等推理模型时，有几个参数差异需要注意：

```python
response = client.chat.completions.create(
    model="o3",
    messages=[{"role": "user", "content": "证明 e 是无理数"}],
    max_completion_tokens=16000,  # 注意：用 max_completion_tokens 而非 max_tokens
    # temperature 仅支持 1（默认值）
    # 不要传 top_p 参数
)
```

<Warning>
  推理模型的 `temperature` 只支持设为 1，且不支持 `top_p` 参数。输出请用 `max_completion_tokens` 控制。
</Warning>
