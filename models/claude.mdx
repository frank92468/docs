## 基本调用

所有 Claude 模型使用 OpenAI 兼容格式调用，无需 Anthropic SDK：

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的API密钥",
    base_url="https://api.seeoneapi.com/v1"
)

response = client.chat.completions.create(
    model="claude-sonnet-4-5-20250929",
    max_tokens=4096,
    messages=[
        {"role": "system", "content": "你是一个有帮助的助手"},
        {"role": "user", "content": "解释一下量子计算的基本原理"}
    ]
)

print(response.choices[0].message.content)
```

```javascript Node.js
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-你的API密钥',
  baseURL: 'https://api.seeoneapi.com/v1',
});

const response = await client.chat.completions.create({
  model: 'claude-sonnet-4-5-20250929',
  max_tokens: 4096,
  messages: [
    { role: 'system', content: '你是一个有帮助的助手' },
    { role: 'user', content: '解释一下量子计算的基本原理' }
  ],
});

console.log(response.choices[0].message.content);
```

```bash cURL
curl https://api.seeoneapi.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的API密钥" \
  -d '{
    "model": "claude-sonnet-4-5-20250929",
    "max_tokens": 4096,
    "messages": [
      {"role": "system", "content": "你是一个有帮助的助手"},
      {"role": "user", "content": "解释一下量子计算的基本原理"}
    ]
  }'
```

</CodeGroup>

## 支持的功能

<AccordionGroup>
  <Accordion title="流式输出">
    设置 `stream=True` 即可获得流式响应，适合聊天界面和实时展示：

    ```python
    stream = client.chat.completions.create(
        model="claude-sonnet-4-5-20250929",
        messages=[{"role": "user", "content": "写一首诗"}],
        stream=True
    )

    for chunk in stream:
        if chunk.choices[0].delta.content:
            print(chunk.choices[0].delta.content, end="")
    ```
  </Accordion>

  <Accordion title="多轮对话">
    通过 messages 数组传递对话历史，模型会基于上下文进行回复：

    ```python
    messages = [
        {"role": "user", "content": "我在学 Python"},
        {"role": "assistant", "content": "很好！Python 是一门很棒的语言..."},
        {"role": "user", "content": "能推荐一些入门资源吗？"}
    ]
    ```
  </Accordion>

  <Accordion title="System Prompt">
    使用 system 角色设定助手行为，这对控制输出风格和格式非常有效：

    ```python
    messages = [
        {"role": "system", "content": "你是一位资深的代码审查专家。请用中文回复，指出代码问题并给出改进建议。"},
        {"role": "user", "content": "请审查以下代码..."}
    ]
    ```
  </Accordion>

  <Accordion title="Thinking 模式（思维链）">
    使用 `-thinking` 后缀的模型可以显示完整的推理过程，适合复杂问题：

    ```python
    response = client.chat.completions.create(
        model="claude-sonnet-4-5-20250929-thinking",
        max_tokens=16000,
        messages=[
            {"role": "user", "content": "证明根号2是无理数"}
        ]
    )
    ```

    <Warning>
      Thinking 模型的输出会包含思考过程，Token 消耗较大。建议设置较高的 `max_tokens`。
    </Warning>
  </Accordion>
</AccordionGroup>

## 模型选择建议

| 你的需求 | 推荐模型 | 理由 |
|---------|---------|------|
| 日常开发、写代码 | Claude Sonnet 4.5 | 编程能力顶级，性价比高 |
| 快速分类、摘要、简单问答 | Claude Haiku 4.5 | 速度快 2 倍+，成本最低 |
| 数学证明、复杂架构设计 | Claude Opus 4.5 | 当前 SWE-bench 最高分 |
| 需要看到推理过程 | Sonnet 4.5 Thinking | 思维链模式，调试推理逻辑 |
