## 我们的承诺

SeeOneAPI 以**稳定、透明、可信赖**为核心价值。我们相信，一个好的 API 服务商不仅要提供好用的接口，更要让用户安心。

## 价格透明

- 所有模型倍率在控制台公开可查
- 价格调整提前通知
- 不设隐藏收费项目

## 服务稳定

- 企业级基础设施，多节点部署
- 持续监控，快速响应故障
- 定期发布可用性报告

## 数据安全

- 不存储用户的 API 请求和响应内容
- API Key 加密存储
- 详见[数据安全](/trust/data-security)页面

## 合规经营

- 合法注册的商业实体
- 通过正规渠道获取上游 API 访问
- 详见[合规说明](/trust/compliance)页面

<Info>
  我们深知信任是需要长期建立的。如果你有任何安全方面的疑问，欢迎随时联系我们。
</Info>
