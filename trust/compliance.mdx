## 合法经营

SeeOneAPI 由合法注册的商业实体运营，我们承诺通过正规渠道获取所有上游 API 访问权限。

## 上游渠道

- 所有模型通过官方或授权渠道接入
- 我们持续维护与上游提供商的合规关系
- 渠道变动时会及时通知用户

## 用户责任

使用 SeeOneAPI 时，请遵守以下规范：

- 遵守上游模型提供商（Anthropic、OpenAI）的使用政策
- 不使用 API 生成违法违规内容
- 不尝试逆向工程或滥用 API 服务
- 合理使用 API 资源，不恶意刷量

## 服务承诺

- **提前通知**：重大变更（价格调整、模型下线等）提前通知
- **数据透明**：用量和账单数据随时可查
- **快速响应**：服务异常时第一时间公告和修复

## 免责声明

SeeOneAPI 提供 API 中转服务。模型的输出内容由上游模型提供商（Anthropic、OpenAI）的模型生成，SeeOneAPI 不对模型输出内容的准确性、完整性或适用性做出保证。

用户应对自己使用 API 的方式和目的负责。
