## 数据处理原则

SeeOneAPI 作为 API 中转服务，遵循**最小化数据接触**原则：

### 我们不做的事

- **不存储对话内容**：你的 API 请求和响应内容仅用于实时转发，不做任何持久化存储
- **不训练模型**：你的数据不会被用于任何模型训练
- **不分析内容**：我们不对你的请求内容做任何形式的分析或挖掘
- **不向第三方分享**：除了转发给上游模型提供商（Anthropic / OpenAI），你的数据不会发送给任何第三方

### 我们会记录的信息

为了提供账单和基本运维能力，我们会记录：

- 请求时间戳
- 使用的模型名称
- Token 用量（用于计费）
- 请求状态码

这些元数据不包含你的对话内容。

## API Key 安全

- API Key 使用加密存储
- 支持设置额度上限
- 支持随时创建和撤销
- 建议定期轮换

## 传输安全

- 全链路 HTTPS 加密
- TLS 1.2+ 

## 建议

为了最大化你的数据安全：

1. 不要在 API 请求中发送敏感个人信息（身份证号、银行卡号等）
2. 为不同项目使用独立的 API Key
3. 定期检查控制台的用量记录，确认无异常调用
