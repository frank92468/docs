## 通用接入方法

不管哪种工具，核心配置就两项：

| 配置项 | 填写 |
|--------|------|
| Base URL / API Host | `https://api.seeoneapi.com/v1`（部分工具不带 `/v1`） |
| API Key | 控制台创建的令牌（`sk-` 开头） |

```python
# 所有兼容 OpenAI 格式的工具，只需要改这两行
client = OpenAI(
    api_key="sk-你的API密钥",
    base_url="https://api.seeoneapi.com/v1"
)
```

## 环境变量方式（通用）

很多工具支持通过环境变量自动读取配置：

```bash
export OPENAI_API_KEY="sk-你的API密钥"
export OPENAI_BASE_URL="https://api.seeoneapi.com/v1"
```

设置后，所有读取这两个环境变量的工具都会自动使用 SeeOneAPI。
