## LangChain

[LangChain](https://github.com/langchain-ai/langchain) 是最流行的 LLM 应用开发框架。SeeOneAPI 可以通过 `langchain-openai` 包直接接入。

### 安装

```bash
pip install langchain-openai
```

### 基本用法

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="claude-sonnet-4-5-20250929",
    api_key="sk-你的API密钥",
    base_url="https://api.seeoneapi.com/v1",
    temperature=0.7
)

response = llm.invoke("用一段话介绍 SeeOneAPI")
print(response.content)
```

### 多轮对话

```python
from langchain.schema import HumanMessage, SystemMessage

messages = [
    SystemMessage(content="你是一个 Python 专家"),
    HumanMessage(content="如何用 Python 实现一个简单的 Web 服务器？")
]

response = llm.invoke(messages)
print(response.content)
```

### 流式输出

```python
for chunk in llm.stream("写一首关于编程的诗"):
    print(chunk.content, end="")
```

## Dify

[Dify](https://dify.ai/) 是一款开源的 LLM 应用开发平台，支持可视化编排工作流。

1. 进入 Dify 控制台 → 设置 → 模型供应商
2. 添加模型供应商，选择 **OpenAI-API-compatible**
3. 填入：

| 字段 | 值 |
|------|------|
| Model Name | `claude-sonnet-4-5-20250929`（按需填写） |
| API Key | `sk-你的API密钥` |
| API Endpoint URL | `https://api.seeoneapi.com/v1` |

4. 保存后即可在 Dify 的应用和工作流中使用该模型

<Tip>
  Dify 中可以添加多个模型供应商，建议把常用的 Claude 和 GPT 模型都配置好，方便在工作流中按需切换。
</Tip>

## 通过环境变量接入

如果你的框架或应用支持读取 OpenAI 环境变量，最简单的方式：

```bash
export OPENAI_API_KEY="sk-你的API密钥"
export OPENAI_BASE_URL="https://api.seeoneapi.com/v1"
```

大部分基于 OpenAI SDK 构建的框架（如 AutoGen、CrewAI、Haystack 等）都会自动读取这些环境变量。
