[Chatbox](https://chatboxai.app/) 是一款简洁的跨平台客户端，支持 Windows / macOS / Linux / iOS / Android。

## 配置步骤

1. 打开设置 → **AI 模型提供方**
2. 选择 **OpenAI API 兼容**
3. 填入：

| 字段 | 值 |
|------|------|
| API Domain | `https://api.seeoneapi.com` |
| API Key | `sk-你的API密钥` |
| Model | `claude-sonnet-4-5-20250929` |

4. 保存后即可使用

## 注意事项

- Chatbox 需要手动填写模型名，从 [模型广场](https://www.seeoneapi.com/pricing) 复制模型 ID
- 支持在设置中配置多个模型，方便切换
